# 📚 Panduan Lengkap Mengonlinekan Media Ajar Kalor Secara GRATIS

Media Ajar Digital Kalor ini dibuat menggunakan **HTML5, CSS3, dan Vanilla JavaScript (Zero Dependency)**. Artinya, website ini **100% statis, sangat cepat, ringan, dan tidak memerlukan server backend atau database**. Anda bisa mengonlinekannya secara **GRATIS selamanya** menggunakan beberapa metode mudah di bawah ini.

---

## 🌟 Metode 1: Netlify Drop (Paling Mudah & Instan — Tanpa Perlu Akun GitHub)

Metode ini paling cocok jika Anda ingin website langsung aktif dalam **30 detik** cukup dengan *Drag & Drop* (tarik dan lepas folder):

1. Buka browser dan kunjungi: **[https://app.netlify.com/drop](https://app.netlify.com/drop)**
2. Jika diminta login/daftar, Anda bisa daftar gratis menggunakan akun Google atau email biasa.
3. Setelah masuk ke halaman Netlify Drop, akan muncul kotak bertuliskan *"Drag and drop your site output folder here"*.
4. Buka File Explorer di komputer Anda, lalu **tarik (drag) seluruh folder `Media Ajar`** ke dalam kotak tersebut.
5. Tunggu sekitar 5-10 detik. Netlify akan langsung memberikan link website aktif, contohnya:  
   `https://random-name-12345.netlify.app`
6. **Ubah nama link agar cantik:**
   - Masuk ke menu **Site configuration** ➔ **Change site name**.
   - Ganti namanya menjadi, misalnya: `kalor-smp7-seru.netlify.app`.
   - Sekarang link tersebut siap dibagikan ke seluruh murid Anda! 🎉

---

## 🚀 Metode 2: GitHub Pages (Sangat Populer, Resmi & Permanen)

Metode ini sangat disukai pendidik karena link permanen dan terhubung dengan portofolio digital:

1. Buka dan login ke **[https://github.com](https://github.com)** (buat akun jika belum punya).
2. Klik tombol **New Repository** (atau tanda `+` di kanan atas).
3. Beri nama repository, misalnya: `media-ajar-kalor`.
4. Pilih opsi **Public**, lalu klik **Create repository**.
5. Di halaman repository yang baru dibuat, klik **Upload an existing file**.
6. Tarik file `index.html` serta folder `css` dan `js` ke halaman tersebut, lalu klik **Commit changes**.
7. Buka tab **Settings** di repository tersebut:
   - Pilih menu **Pages** di bilah sebelah kiri.
   - Di bagian **Branch**, pilih `main` (atau `master`) dan folder `/ (root)`.
   - Klik tombol **Save**.
8. Tunggu 1–2 menit, refresh halaman. Link website Anda akan muncul di bagian atas:  
   `https://[username-anda].github.io/media-ajar-kalor/`

---

## ⚡ Metode 3: Vercel (Super Cepat & Modern)

1. Buka **[https://vercel.com](https://vercel.com)** dan login dengan Google atau GitHub.
2. Klik tombol **Add New...** ➔ **Project**.
3. Hubungkan dengan repository GitHub Anda yang dibuat di Metode 2 (atau gunakan Vercel CLI).
4. Klik tombol **Deploy**.
5. Dalam 10 detik, website Anda langsung online dengan domain seperti:  
   `https://media-ajar-kalor.vercel.app`

---

## 📲 Tips Praktis untuk Mengajar di Kelas 7:
- **Buat QR Code:** Buka situs gratis seperti *me-qr.com* atau *qr-code-generator.com*, masukkan link website Anda, lalu tempelkan QR Code tersebut di slide presentasi proyektor atau lembar kerja siswa.
- **Bisa Diakses di HP/Tablet:** Desain flipbook sudah responsif otomatis untuk layar smartphone murid.
- **Bisa Digunakan Offline:** Jika lab komputer sekolah sedang tidak ada internet, cukup copy folder `Media Ajar` ke flashdisk, lalu buka file `index.html` dengan klik ganda di browser apa pun (Google Chrome, Edge, Firefox)!
